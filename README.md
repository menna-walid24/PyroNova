# PyroNova – Flame in Freefall

**PyroNova** is an intelligent fire safety and survival assistant designed to support astronauts in preventing and responding to fire emergencies in space.

The project consists of an interconnected **mobile application**, a **web platform**, and a centralized **backend** that manages authentication, user data, communication between the two platforms, and AI integration.

## 🚀 Project Components

### 1. Mobile Application

The mobile application is designed to simulate fire emergency scenarios and help astronauts understand the initial steps they should take when a fire occurs.

Its main features include:

* **Fire Emergency Simulation:** Allows users to simulate a fire emergency and receive the initial response procedures they should follow.
* **Emergency Notifications:** Sends alerts to other astronauts assigned to the same spacecraft module.
* **AI Assistant:** Provides an interactive chatbot powered by an AI Agent to help users access relevant fire-safety information.

### 2. Backend

The backend serves as the central system connecting the mobile application and the web platform.

Its responsibilities include:

* **Authentication:** Manages user registration and login using Laravel Sanctum.
* **Shared User Data:** Keeps user accounts and associated information connected across both platforms.
* **Emergency Management:** Handles fire emergency simulations and provides initial response procedures.
* **Push Notifications:** Sends emergency alerts to astronauts belonging to the same spacecraft module.
* **AI Integration:** Connects the applications to the AI services and handles communication with the AI Assistant.

### 3. Web Platform

The web platform provides an interactive environment for exploring fire behavior under different conditions using real NASA data.

Its main features include:

* **AI Dashboard:** Displays real experimental data and visualizes how fire behaves under different conditions.
* **AI Chatbot:** Allows users to interact with the AI system, ask questions, and explore information related to space fire safety.

##  Technologies Used

* **Backend:** Laravel, Laravel Sanctum.
* **AI:** AI Agent.
* **Mobile Application:** Kotlin.
* **Data Sources:** NASA Physical Sciences Informatics (PSI).
